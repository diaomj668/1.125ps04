# Sources and Independence

The configuration currently includes seven candidate publishers: Simon Willison, GitHub, Cursor, Fireship, Web Dev Simplified, HTML All The Things, and Changelog/Practical AI.

Different producers do not necessarily provide independent perspectives or independent evidence for a claim. Attribute GitHub and Cursor product information as vendor statements. Developers may have sponsors; disclose relevant incentives in selection reasons.

Channel or show independence is not claim independence. Repetition of the same announcement is one underlying claim. A podcast and its YouTube upload count as one item.

Discovery metadata is not a substitute for retained substantive text, downloaded audio, or timestamped transcripts. Actual collection records belong in the live run directory.

Normalized transcript hashes only detect identical transcriptions. Edited clips, reuploads, and different transcriptions of the same recording still need human reconciliation. Count one underlying item and explain any merge.

Coverage favors English-language technical communities, vendors, and experienced developers. First-time users, unsuccessful projects, budget-constrained individual developers, and accessibility experiences may be missing. Do not transfer large-team productivity claims directly to individual developers.

The current clean run does not provide independent controlled small-project productivity research. A vendor benchmark is a research perspective with commercial incentives, not independent confirmation. Do not infer general productivity gains from this corpus.
