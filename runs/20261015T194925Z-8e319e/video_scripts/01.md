# Beyond code generation: remote control, security review and runtime inspection
As of: 2026-10-15

**Visual direction:** Opening title card for Google Vids or HeyGen. Plan for synthetic narration, with a visible disclosure: “AI-generated narration.” Show three labeled icons: remote interaction, security review, runtime inspection. All interface diagrams should be labeled illustrative, not product demonstrations.

**Narration:**
As of October 15, 2026, some concrete AI coding developments extend beyond writing code. They offer ways to supervise an agent remotely, request security findings, and inspect running software. For someone building a small app or script alone, those are capabilities worth investigating. They are not evidence that a project can now finish itself.

**Visual direction:** Connect a phone icon to a laptop. Keep the agent icon inside the laptop. Add “Computer must stay on and online.”

**Narration:**
First, Cursor announced that its iOS app can display local agents and let you message them. Here, an agent means the assistant carrying out development work. The important distinction is where that work happens: it still runs on your computer. The phone connects to it; it does not move the task into cloud execution. Your computer must remain on and online. That gives you another way to interact with ongoing work, not a different place for the work to run.

**Narration:**
Second, Cursor announced Security Review for selected repositories. Its advertised findings contain a severity, an attack path, and a proposed fix. An attack path describes how the reported problem could be reached or exploited. Draft pull requests are skipped, and access is offered on Teams and Enterprise plans. For an individual developer, eligibility and purchase practicality therefore matter. The announcement establishes the proposed review format and access restrictions. It does not establish how effectively the tool detects vulnerabilities.
